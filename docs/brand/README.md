# Coquí brand kit

Named for the coquí, the tiny tree frog of Puerto Rico. The mark is a coquí seen from above, mid-crawl: glinting eyes, faint back stripes, round toe pads. The wordmark's "o" and "q" are her eyes, peeking over the word.

## Files

| File | Use |
| --- | --- |
| `coqui-mark.svg` | Primary mark, full color, transparent background |
| `coqui-mark-mono-dark.svg` / `-mono-light.svg` | One-color mark for light / dark backgrounds |
| `coqui-wordmark.svg` / `-light.svg` | Peeking wordmark for light / dark backgrounds |
| `coqui-lockup.svg` / `-light.svg` | Mark + wordmark, horizontal |
| `coqui-icon.svg`, `coqui-icon-1024.png` | App icon (night rounded square), source for `tauri icon` |
| `coqui-favicon.svg` | Simplified mark for 16–48 px |

## Type

Bricolage Grotesque (headlines), Inter (UI and data). The wordmark is drawn, not typeset — use the SVG.

## Rules

- Below 64 px use `coqui-favicon.svg` (no toes or stripes).
- Keep clear space of one eye-width around the mark.
- Don't recolor the frog green; amber is her real color.
